# Procedencia de recursos

| Recurso                           | Procedencia y permiso                                                                                                                                                                                                      | Uso                                                                                                                               |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `artworks/a1.png`–`a6.png`        | Composiciones geométricas originales generadas proceduralmente para esta demo con `scripts/create_fixtures.py`; sin imágenes de terceros o del moodboard. Se distribuyen bajo CC0 1.0 para su reutilización como fixtures. | Seis obras ficticias; los nombres de artistas son personajes demo, no atribuciones de creación real.                              |
| Poppins Regular, Medium, SemiBold | Repositorio oficial [google/fonts, ofl/poppins](https://github.com/google/fonts/tree/main/ofl/poppins), descargado el 10-11-2026. SIL Open Font License 1.1, copia íntegra en `fonts/OFL.txt`.                             | Interfaz; Regular/SemiBold también en PDF nativo. Se obtuvo la familia oficial porque no se recibió el ZIP de fuentes mencionado. |
| Iconos Feather                    | [Feather](https://github.com/feathericons/feather), MIT, vía `@expo/vector-icons`; licencias en `licenses/`.                                                                                                               | Iconos lineales con texto o etiqueta accesible.                                                                                   |
| Logo final Artium                 | Imagen original proporcionada por el usuario en el chat; titularidad de su autor, no se relicencia. No disponible como archivo binario en el entorno.                                                                      | Integración preparada, no reconstruido. Cuando se incorpore, se copiará exactamente como `brand/logo-final.png`.                  |

No se incluyen como obras de usuarios los materiales del moodboard, bocetos, matrices o propuestas descartadas. No se distribuye el temario de UNIR dentro del paquete del software. Universidades y perfiles se usan solo como datos de demostración, sin afiliación verificada.

CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/ — la dedicación se aplica únicamente a las seis composiciones de prueba generadas para este proyecto, no al logo, fuentes, dependencias o documentos del usuario.
